
# Amazon Customer Sentiment Analysis

## Project Overview
This project analyzes Amazon customer reviews to understand customer sentiment, product ratings, and feedback patterns using Microsoft Power BI.

## Objectives
- Analyze positive, negative, and neutral customer reviews.
- Compare sentiment across product categories and star ratings.
- Track average product ratings over time.
- Identify categories with a high number of negative reviews.

## Tools Used
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and KPIs
- CSV dataset

## Dashboard Highlights
- Total Reviews
- Average Rating
- Positive, Negative, and Neutral Review Percentages
- Sentiment Distribution Across Star Ratings
- Sentiment by Product Category
- Overall Sentiment Distribution
- Negative Reviews by Product Category
- Average Rating by Product Category
- Average Rating Trend

## Key Findings
- Total reviews analyzed: 5,000
- Average rating: 3.49 out of 5
- Positive reviews: 53.26%
- Negative reviews: 28.32%
- Neutral reviews: 18.42%

*These results reflect the dataset used in this project.*
